# LUEMI — обязательные правила разработки

Действуют для всех будущих задач LUEMI: регистрации, Discovery, профиля, чатов, Stories/«Блики», Premium и административных экранов.

1. **Читай соседний код до правки:** компонент, хуки, CSS, тесты, пользователей общих классов/жестов, соседние экраны.
2. **Один владелец движения:** нельзя конкурировать за scrollTop/transform/opacity/height из CSS, JS, таймеров, RAF и WAAPI.
3. **Удаляй заменённую реализацию целиком**, включая мёртвые стили, переменные, слушатели и устаревшие тесты. Заплатки-слои запрещены.
4. **В горячем пути анимируй transform/opacity:** никакого покадрового radius, shadows, filters, layout-геометрии или CSS-переменных; никакого чтения layout в scroll/touch/RAF.
5. **Осторожно со стеклом:** moving backdrop-filter, mix-blend, mask-image, SVG-фильтры запрещены. На экране максимум 1–2 неподвижных blur-поверхности.
6. **will-change ограничен** 2–3 слоями и снимается при остановке там, где управление динамическое.
7. **Не держи скрытые экраны с активными подписками**: window/document/ResizeObserver, таймеры и WebApp listeners должны освобождаться.
8. **Стабильные props и подписки:** useCallback/useMemo/ref для зависимостей эффектов, особенно Telegram BackButton.
9. **Сначала нативные механизмы:** CSS scroll snap/scroll timeline/IntersectionObserver. Самодельная JS-физика и scrollTo-доводчики запрещены.
10. **Проверяй на Galaxy A55** в Chrome и Telegram WebView, когда устройство доступно: DevTools Performance, ориентир 55–60 FPS и отсутствие long tasks. CI никогда не заменяет аппаратный тест.
11. **Prettier обязателен:** `npm run format` для подготовки, `npm run format:check` в CI; экранный CSS отдельно, читаемые TSX без однострочных простыней.
12. **После задачи зелёные** `npm run format:check`, `npm run check`, `npm test`, `npm run build`, `npm run smoke`. Устаревшие тесты обновлять, не удалять.
13. **В отчёте перечислить:** удалённое, добавленное, соседние разделы с аналогичными рисками и ограничения QA.
14. **Границы:** LUEMI отдельный сервис/репозиторий; никогда не менять VEYRA или blotX; никаких новых платежей и секретов без отдельного согласования.
