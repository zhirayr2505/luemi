# LUEMI — Stage 00 / новая кодовая база

Основание: владелец разрешил независимую повторную реализацию по утверждённым материалам и создал `zhirayr2505/luemi`.

## Готовность
- [x] Изолированный репозиторий LUEMI.
- [x] React/TypeScript/Vite; адаптивный Soft Glass, светлая/тёмная тема.
- [x] Интерактивная восьмишаговая локальная регистрация, проверки 18+, 3–6 фото и 15 интересов.
- [x] Демо-Лента, Симпатии, Чаты, Профиль, полноэкранная локальная переписка.
- [x] Fastify health endpoint и контейнер Render free.
- [ ] Импорт оригинальных approved W12 assets (включая оригинальный wordmark); текущий fallback — временный.
- [ ] Pixel QA с тремя эталонами и проверка интерфейса на Galaxy A55 в Telegram.
- [ ] Telegram HMAC, backend session, PostgreSQL, Supabase, закрытое хранилище медиа, RLS.
- [ ] Реальные пользователи, модерация, география, чаты, web socket и бот.
- [ ] Stars, LUME, Premium — отдельный этап после серверного ledger и утверждения цен.

## Границы
**ДЕМО** — все действия локальные. Нет реальных лайков, мэтчей и доставки сообщений.
Оригинальные JPG/PNG бренда и эталонов сохраняются в исходном передаточном архиве; они не меняются. Тёмные дополнительные макеты и численные дизайн-токены не объявляются APPROVED без проверки.
Секреты, настоящие фото, продакшен-данные не включать. Платные тарифы не активировать.
