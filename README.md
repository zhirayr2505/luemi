# LUEMI 💜

Новая независимая кодовая база LUEMI — глобального 18+ Telegram Mini App для знакомств.

**Статус:** Stage 00 — интерактивная демонстрация UI, **не** запущенный сервис знакомств. Переписка, лайки и профили в этой версии работают только локально в деморежиме. Оплата, реальные пользователи, загрузка на сервер и модерация выключены.

## Запуск
```bash
npm install
npm run check
npm test
npm run build
npm run dev
```

## Архитектура
- `apps/web` — React 19 + TypeScript + Vite, мобильный Soft Glass UI.
- `apps/api` — отдельный Fastify web/API bootstrap (пока только health/readiness + статика).
- `docs` — границы этапа, нормативные требования и задачи до беты.
- `render.yaml` — отдельный **бесплатный** сервис LUEMI; без доступа к VEYRA/blotX.

## Канонические материалы
Источник требований: LUEMI Brand Master v2.4, паспорт v2.4-W12, проверенные экраны регистрации, ленты и чата, библиотека W12. Созданы и утверждены **до** этой новой кодовой базы. Исторические макеты не меняются.

Исходный визуальный пакет пока ожидает добавления в `apps/web/public/assets`: оригинальный логотип, approved PNG, W05–W12. В отсутствие ресурса используется временное текстовое отображение. **Временное отображение не считается утверждённым изменением логотипа.** Не заменять оригинал самодельным SVG.

Безопасность: токены Telegram, ключи Supabase и реальные фото никогда не коммитить. Не включать платежи без отдельного согласования и серверной проверки.
